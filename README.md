# 🧮 Command-Line Calculator in C

## 📌 About the Project
This project is a simple command-line calculator developed using the C programming language. It performs basic arithmetic operations using **functions and switch statements**.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven operation selection
- Prevents division by zero

## 🛠️ Technologies Used
- C Programming Language
- GCC Compiler

## 📂 Project Structure
- `calculator.c` - Source code of the calculator.
- `README.md` - Project documentation.

## 🚀 How to Run

### 1. Compile the Program
Open a terminal in the project folder and enter:

```bash
gcc calculator.c -o calculator
```

### 2. Run the Program

**For Linux, macOS, or GitHub Codespaces:**

```bash
./calculator
```

**For Windows:**

```bash
calculator.exe
```

## 🎮 How to Use
1. Enter the first number.
2. Enter the second number.
3. Choose an operation from the menu:
   - `1` - Addition
   - `2` - Subtraction
   - `3` - Multiplication
   - `4` - Division
4. The calculator displays the result.

## 💻 Sample Output

```text
Enter first number: 10
Enter second number: 5

1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1
Result = 15.00
```

- Understanding functions in C

- Displaying output with printf()
